# ProjectScale Fiverr Gallery Asset Spec

Prepared for owner-authenticated publication. This file turns the existing Gig launch kit into exact gallery assets without using client data, third-party logos, ratings, seller badges, contact information, or misleading claims.

Verified against Fiverr Help Center on 2026-08-16:
- At least one Gig image is required to publish.
- Recommended Gig image size: 1280 x 769 px at 72 DPI; minimum 712 x 430; up to three images.
- Keep image-overlay text short (Fiverr recommends no more than 10 words).
- Images must directly relate to the service and be owned/authorized.
- Do not put contact information, Fiverr badges/levels, or misleading/clickbait claims in the images.
- Optional PDFs may be used as work samples; only the first three pages are displayed.

## Publication QA
- Use only fictional/synthetic sample data unless explicit client permission exists.
- Ensure every image is sharp and readable at thumbnail size.
- Confirm dimensions before upload.
- Keep overlay text concise.
- Do not include email, phone, website, Stripe URL, social handle, Fiverr badge/level, or claims about reviews/sales.
- Do not claim guaranteed accuracy, guaranteed turnaround, certifications, privacy/security/compliance credentials, or outcomes not supported by the actual package.
- Re-check the authenticated Fiverr create-Gig UI for any category-specific mandatory package fields/minimums before publication; Fiverr standardized package requirements can vary by category.
