## Project summary
Foremanly Systems cleans and validates clearly defined CSV and Excel spreadsheet projects while preserving the original source file unchanged.

Typical checks include duplicates under an agreed rule, missing values, inconsistent dates/casing/whitespace, numeric and identifier formats, malformed rows, shifted fields, and inconsistent headers.

Cleanup tiers include a cleaned working file, concise quality report, change and exception documentation, and validation against the agreed project checks. Ambiguous cases are flagged rather than guessed, and missing values are not invented without an explicit deterministic rule.

This service is best for bounded data-quality work. Large or unrelated file sets, complex destination mapping, sensitive-data commitments, external enrichment, APIs, or reusable automation require separate scope.

## Project steps

1. **Scope and rule validation** — review the submitted file details, duplicate/removal rules, required fields, output format, and acceptance checks; identify unresolved questions before changing data.
2. **Preserved-copy cleanup** — preserve the source, work from a copy, run the agreed data-quality checks, and apply bounded corrections.
3. **Post-clean validation and documentation** — reconcile counts and rules, document changes/exceptions, and prepare the purchased deliverables.

## FAQ
### Will the original file be changed?
No. Foremanly preserves the source and applies cleanup to a working copy.

### Will you automatically remove duplicates?
Only when the duplicate rule and removal action are explicit. Ambiguous cases can be flagged.

### Do you fill blank values?
Not by assumption. Missing values remain blank/flagged unless a deterministic fill rule is explicitly supplied.

### What is included in a cleanup tier?
The cleaned working file, concise quality report, change/exception documentation, and validation against agreed checks.

### Can this prepare data for a specific import?
Yes when destination requirements are supplied and the selected scope fits. Platform acceptance is not guaranteed because account configuration and current platform behavior can affect imports.

### What if my project is bigger than the listed tier?
Foremanly should rescope it rather than silently squeeze a larger or more ambiguous project into a starter package.
