How a ProjectScale data service works

Choose a fixed-scope service, pay through Stripe, then send only the files and instructions needed for the work. Ambiguous data is preserved or flagged rather than guessed.

1. Choose the smallest service that fits

Use the service chooser, compare all services, or run the free browser-side CSV check. If you only need an issue report, use the $15 audit. If you need a cleaned output, use cleanup or a larger scoped service.

2. Complete the listed Stripe checkout

Each paid service uses its own Stripe checkout link. Do not send card numbers, passwords, API keys, login credentials, or other payment credentials by email.

3. Send the source file and a short brief

After checkout, follow the post-purchase intake checklist. Email projectscale001@gmail.com with the source file, the service purchased, and the desired result. Include any required column names, formatting conventions, duplicate rules, or fields that must not change.

For import-ready work, include the destination template or documented field specification when available.

4. Processing follows explicit rules

The original source is preserved. Requested transformations are applied using explicit, reviewable rules. Missing facts are not invented. Invalid or ambiguous values are left unchanged or flagged unless an authoritative rule supplied with the job resolves them.

5. Receive the output plus a concise work summary

The delivered result includes the requested file output and a short description of material transformations or exceptions. Larger scope, unsupported formats, external-system access, changing requirements, or additional integrations require separate agreement before work proceeds.

Before purchasing

  • Review the row/file limits on the selected service.
  • Do not submit passwords, secret keys, payment-card data, or credentials.
  • Do not send data you are not authorized to provide for processing.
  • For recurring work, use the monthly plan only when the listed monthly scope fits your needs.
