Purchased a service?

Send these items so work can begin

After completing the listed Stripe checkout, email the source material and a short brief to projectscale001@gmail.com. Please send only information needed for the purchased scope.

First: help us match your payment

  • The name of the service you purchased.
  • The purchaser name and email address used at Stripe checkout.
  • If Stripe provided a receipt or payment reference, include it. You may forward the receipt, but do not send card numbers or other payment credentials.

Work begins only after the corresponding completed payment can be matched to the intake. An email or attached file by itself is not treated as proof of payment.

Intake checklist

  • The source CSV file or files covered by that service.
  • A one- or two-sentence description of the desired result.
  • Any required column names, formatting conventions, duplicate rules, or fields that must remain unchanged.
  • For import-ready work, the destination template or documented field specification when available.

Service-specific details

Include the applicable details below so the first review can stay inside the purchased scope.

  • $15 Data Quality Audit: identify the CSV to review and any columns or known concerns you want emphasized. No cleanup instructions are required unless separately purchased.
  • $35 Cleanup + Normalization: state the desired column names/formatting, duplicate rule, and any fields that must remain unchanged.
  • $49 Contractor Job-Cost Normalization: identify the job/project, cost/category, vendor, date, quantity, and amount fields when known, plus the target import/report layout if one exists.
  • $99 Multi-File Processing Sprint: list the covered files, explain how they relate, identify the desired combined output, and flag any cross-file matching key such as customer ID, SKU, job number, or date.
  • $59/month Data Maintenance: identify which monthly request this is, the source file(s), the recurring rules to reuse, and any rule that changed since the previous request.

Please do not send

  • Passwords, API keys, login credentials, payment-card data, or secret tokens.
  • Files or data you are not authorized to provide for processing.

What happens next

After payment is matched, the original source is preserved. Requested transformations follow explicit, reviewable rules. Missing facts are not invented; ambiguous values are preserved or flagged unless an authoritative rule supplied with the job resolves them. The delivered result includes the requested output and a concise summary of material transformations or exceptions.

If the request exceeds the purchased limits, uses an unsupported format, requires external-system access, or introduces changing requirements, separate scope is required before that additional work proceeds.
