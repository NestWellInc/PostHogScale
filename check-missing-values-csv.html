How to Check Missing Values in a CSV

Missing values appear in more forms than an empty cell. A CSV may use blank text, spaces, or markers such as N/A and null. A useful check distinguishes those representations and reports where they occur.

Define what missing means

Start with the file's business rules. A blank middle name may be acceptable, while a blank order ID may prevent a record from being matched. Treating every blank the same can produce noisy findings or incorrect replacements.

Check missing values by column

  1. List the representations that count as missing.
  2. Count them separately for each column.
  3. Compare the counts with required-field rules.
  4. Inspect records where several important fields are missing.
  5. Record findings before choosing replacements.

Why an audit should not invent values

A deterministic check can locate missing data, but it cannot know an absent business fact. Filling blanks with zero, a date, or a category can change meaning. The fixed-scope audit reports issues and preserves the source; correction rules require clear instructions.
