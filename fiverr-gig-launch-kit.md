## Gig description
Messy CSV or Excel data can create duplicate records, inconsistent formats, broken imports, and unreliable reporting.

I provide bounded, reviewable spreadsheet cleanup based on the rules you supply. Depending on the selected package, work can include duplicate handling, formatting normalization, validation checks, column cleanup, and a concise summary of material changes or exceptions.

The original source is preserved. Ambiguous values are not silently invented: they are preserved or flagged unless an authoritative rule supplied with the order resolves them.

AI and automation tools may assist the workflow, but every delivery is customized to the order and reviewed before delivery. If you require a non-AI workflow, tell me before ordering so we can confirm whether the request is a fit.

Please contact me before ordering if the work involves unsupported file types, external-system access, changing requirements, sensitive credentials, or unusually large/complex data.

Do not send passwords, API keys, payment-card data, secret tokens, or files you are not authorized to provide.

## FAQ

### Will you change my original file?
No. The source is preserved and work is performed on a copy/output file.

### Can you guess missing values?
No. Missing or ambiguous facts are preserved or flagged unless you provide an authoritative rule that resolves them.

### Do you use AI or automation?
AI and automation may assist the workflow, but the work is customized to your requirements and the final delivery is reviewed. If you require non-AI work, state that before ordering so fit can be confirmed.

### Can you work with PDFs, databases, APIs, or websites?
Those may require separate scope. Do not order a CSV/Excel package assuming external-system access is included.

### Can you handle recurring files?
Yes, when the rules are stable. Recurring maintenance or a reusable workflow can be scoped after the first successful job demonstrates the repeat need.
